## Mini Coffee Shop
- tipo: jogo
- status: online
- tags: React Native, Expo, Zustand
- imagem: assets/img/coffee.svg
- demo: https://exemplo.com/coffee
- repo: https://github.com/seu-usuario/mini-coffee-shop
- destaque: sim

Jogo de cafeteria idle 2D. Você começa com **uma única máquina** e um sonho:
servir o melhor café do bairro.

O que tem lá dentro:

- Loop idle com upgrades automáticos;
- Sprites em pixel art feitos à mão;
- Save local com Zustand + AsyncStorage.

> Feito em 48h para uma game jam. Ainda ganho mensagens sobre ele.

## Painel de Clima
- tipo: site
- status: online
- tags: JavaScript, API, CSS
- imagem: assets/img/clima.svg
- demo: https://exemplo.com/clima
- repo: https://github.com/seu-usuario/painel-clima

Dashboard de clima em página única que consome a API do Open-Meteo.

- Geocodificação com busca instantânea;
- Gráfico de temperatura desenhado em SVG na mão;
- Cache em `localStorage` para economizar requisições.
